# Contributing to DevFest Nova Scotia 2026

Thank you for your interest in contributing to the DevFest Nova Scotia website! 

## Workflow

1. **Fork the repository** to your own GitHub account.
2. **Create a feature branch** from `main` (`git checkout -b feature/amazing-feature`).
3. **Make your changes**, ensuring they align with GDG brand guidelines and the project's aesthetics.
4. **Test your changes** locally using `npm run test` and `npm run dev`.
5. **Commit your changes** following [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/) guidelines.
6. **Push the branch** to your fork.
7. **Open a Pull Request** against the `main` branch and fill out the PR template.

## Conventional Commits
We use semantic-release to automate versioning. Please format your commit messages appropriately (e.g., `feat: added new speaker component`, `fix: corrected button padding`).

If you have any questions, feel free to open a Discussion!
